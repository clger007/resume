## PROJECTS

| **Title** | **Role** | **Project Summary / Responsibilities** |
|-----------|----------|---------------------------------------|
| Cancer Complexity Scoring for Workload Planning with Narrative EMRs (2025) | Lead | Architected NLP pipeline to extract cancer symptom burden (anxiety, depression, pain) from over 2 million EMR notes. Designed sampling strategy, model evaluation benchmarks, and expert-in-the-loop review workflow. |
| Dynamic Detection of Hospital Adverse Events (2024) | Lead | Led LLM-based NLP system for identifying adverse events from unstructured notes. Built annotation tooling, data validation, and fine-tuned classifiers that outperformed ICD-code baselines. |
| Inpatient Fall Detection from Narrative EMRs Using Domain-Specific BERT (2023) | Lead | Developed a hospital-specific BERT model pre-trained on Alberta EMR data to detect inpatient falls from unstructured clinical notes. Designed and evaluated classification pipelines that outperformed ICD-code-based baselines, improving safety surveillance in real-world hospital settings. |
| Automated Pathology Report Interpretation for Breast Cancer (2023) | Lead | Built an NLP system to extract pathologic complete response (pCR) from population-based pathology reports. Developed rule-based and LLM-based methods to identify key cancer outcomes post-neoadjuvant therapy. |
| Health Data Governance for Research Use in Alberta (2023) | Contributor | Contributed to a published provincial study by formalizing fragmented data access and linkage workflows. Translated governance procedures into structured models (UML, data flow diagrams), bridging technical and policy domains to clarify approval, legal, and operational steps for research data access. |
| Using Machine Learning to Aid Qualitative Health Research (2022) | Lead | Developed unsupervised NLP workflow using DistilBERT, UMAP, and HDBSCAN for theme extraction from interview transcripts. Demonstrated alignment with human-coded qualitative results. |
| A Hybrid Semantic Networks Construction Framework for Engineering Design (2022) | Lead | Developed a computational framework to model and structure end-user needs using semantic network representations, enabling better requirement elicitation in engineering design. |
